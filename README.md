# South Asian Holidayz — Free Website

This is a responsive static website recreated from the supplied sketch.

## Files
- `index.html` — website structure
- `styles.css` — layout, colors and responsive design
- `script.js` — mobile navigation
- `assets/` — visual assets used in the design

## Free hosting
### GitHub Pages
1. Create a free GitHub account at https://github.com/
2. Create a new public repository, for example `south-asian-holidayz`.
3. Upload all files from this folder.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**, select `main` and `/root`.
6. Save. GitHub will provide a free `github.io` website address.

### Netlify
Create a free account at https://www.netlify.com/, then drag the entire project folder into Netlify's deploy area.
